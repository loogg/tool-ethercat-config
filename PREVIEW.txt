EtherCAT Atlas · 配置查阅工作台 v1.5.0

运行静态交付包

1. 本机需要 Node.js 22.12 或更高版本。
2. 解压 ZIP，保持 dist、scripts、Start-Tool.cmd 的相对位置。
3. 双击 Start-Tool.cmd，或在此目录执行：node scripts/preview.mjs
4. 浏览器访问：http://127.0.0.1:4181/
5. 命令窗口中按 Ctrl+C 关闭服务。

没有 npm 安装步骤，预览脚本只使用 Node.js 内置模块。
也可以把 dist 内的所有文件部署到自己的静态 HTTP 服务。
不要以 file:// 方式直接双击 dist/index.html；浏览器会限制模块加载。

工具包含 SSC Tool、应用定义文件（Excel）、ESI 设备描述文件的查阅、
全局搜索、双向关联、收藏、最近查阅和五类计算器。
v1.1 默认采用局部配置关系图；对象与子项分层，支持方向切换和缓冲占用演算。
v1.2 应用定义采用工作表与对象表格；选择字段查看说明与局部关系，支持槽位实例预览。
内置普通单体、模块化单实例、模块化双实例的通用示例，不包括具体项目的启动应用。
点击列标题打开填写手册，查可填写值、语法、范围、空白含义与例子。
v1.2.1 补齐普通模板零增量表头；DataType中可查看SSC对象字节/WORD边界与填充图解。
v1.2.2 看门狗页面区分0400共享分频、0410 PDI/PDI0、0420过程数据时间；提供独立触发/停止/禁用的时序教学。
所有搜索与计算都在本地浏览器完成；只有点击参考资料链接时才访问外部网站。

本工具用于配置理解和本地计算，不连接设备，不替代所用 SSC / ESC / ESI 规范。
具体型号、内部处理字宽和功能支持，请按实际手册选择。

v1.3.0 ESI XML 工作台：结构/字段、Device修订、字典、PDO引用、Profile、关系和原文。
支持浏览器内存读取本地XML，未知字段保留；刷新需重新打开。未进行完整XSD验证。
时序工作台参考PulseView/Perfetto/WaveDrom，支持共用轨道、播放、事件选择、
逐事件推进、缩放/平移、A-B测量、参数调整与错误恢复。覆盖看门狗、周期、
物理I/O延迟、AL等待、SDO回调、三缓冲逻辑和CiA402状态。所有演示不是实际采样或设备仿真。
跨文件对应：SSC、应用字段、ESI共用11组带条件和出处的字段规则。
规则关系与当前XML内部引用分开，独立教学文件不会被自动认作同工程产物。

v1.4.0 ESI条目工作页：语义导航、字段内关联、原位说明及局部关系图。
对象成员、PDO、SM位段与模块步长分别呈现；XML原文/引用按需打开。
保留当前字段跳转与返回，支持切换原始XML树，不常驻第三栏。

v1.5.0 独立首页与基础概念：四个主入口、六个主题、29个术语和分步交互图解。
配置页可原位解释术语；保留18个旧概念的技术要点和深链接。
教学场景、当前文件与实际设备状态分别表达；依然只在本地浏览器计算。
