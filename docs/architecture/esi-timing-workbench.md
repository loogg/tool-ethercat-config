# ESI与时序工作台结构

```text
通用教学XML / 本地只读XML
             |
        XML解析与源绑定 -------- 原文、XPath、行范围
             |
   Device/Module作用域的语义模型
             |
   公开字段规则 + Profile解释层
             |
 XML树 / 属性表 / 字典PDO表 / 轴模块 / 局部引用 / 源码

配置项 / 当前XML节点 --- 显式时序适用映射
                              |
                 参数 -> 纯场景模型(轨道/事件/状态)
                              |
             共用时间轴 + 事件解释 + 播放/游标/测量
```

ESI文件正文仅在浏览器内存中保留；运行包只含通用教学XML与资料规则。解析层保留未知节点与原始值，语义模型不反写源文件。版本化规则与未知缺省分开，完整XSD校验不是DOMParser的解析成功状态。

时序内核用显式单位及事件坐标：物理时间示例与逻辑步骤分开，业务模型决定状态，交互层只负责观察、选择和播放。参数校验失败时不显示旧的健康结果。播放速度仅是观看速度，不是设备速度。配置没有时间意义时不提供伪造的时序入口。

跨来源增量采用公共字段契约，详见 [模型评估与三版UML](cross-source-model.md)。各格式适配器保留原始结构，公共规则使用定义端点与条件、版本、证据；无工程绑定时不生成实例同值断言。物理I/O延迟从周期预算分离，使用单独ns轴与物理事件。
