# 当前条目绑定与共享访问模型

2026-10-27，基线v1.6.1。用户要求将协议/存储/访问模型绑定到SSC Tool、应用对象字典和ESI当前上下文，全部实现并验证。

## 范围与方案

```text
APP当前对象/成员/单元格 ──> APP适配器 ──┐
ESI当前Device/Module/Object/Type ─> XML适配器 ─> 带来源/状态的对象定义
                                      ├── 当前成员单项/CA请求 ─> 校验/布局/默认值或??
                                      └── SSC默认存储规则 ─> 规则预览/需适配/未知
SSC当前能力配置 ──> 规则影响模型（无工程配置值时保持未知）
基础概念 ──> 原独立教学模型（单独保留）
```

- 协议类型、源文件布局、SSC默认预期布局、SDO有效数据载荷分别建模。禁止把ESI BitOffs当作已验证C偏移，或给条目固定一个通用size。
- 保存源工作表/行/字段、XML路径/设备修订/模块作用域、声明/默认/生成/未知状态。不按相同Index合并独立文件。
- APP使用当前对象与子项，SI0生成值只标为定义预览；默认值空白保留未知，不用固定0x2002替换当前对象。
- ESI使用当前类型/对象及明确引用；CompleteAccess声明与实际固件支持分开，缺失布尔值不等于false。类型有多个实例时不任意选择实例默认值。
- SSC条目显示当前配置来源、影响条件和关联规则；知识库未载入Config.xml时不虚构已配置0/1。
- 已知且支持的默认值可编码预览，未知字节为??。未知类型/偏移、未展开结构、冲突不猜测。支持已知定长整数/布尔/浮点及源DefaultData；位字段按位组装。长数据按窗口展示。
- 当前条目默认显示精简事实，展开共用工作台；基础概念继续使用教学对象。共享组件按需加载，保留v1.6.1单项点选联动与CA定位规则。

## 依据

沿用已核对的ET9300 V1.10 §§7.1–7.3/13.4、Helmholz §9.5.1和MathWorks CoE布局说明。新增适配需保留源字段原义；未直接取得ETG完整规范，不宣称完整XSD/固件/通用CA编解码验证。

## 验证记录

- 202项测试全部通过（新增22项当前来源语义测试及1项CA主图测试）；既有642种不同关系模型的横/纵正交路由几何回归通过。
- 应用0x2001默认数据：单项SI1 `0A 00`、SI2 `14 00`；CA0 `02 00 0A 00 14 00`，CA1 `0A 00 14 00`。CA点SI2保留原范围；单项点SI2同步请求；CA2显示默认路径中止。
- VARIABLE 0x2000单项使用当前默认10（2Byte），不套用1Byte计数头。两个BOOL只预览各自单项；默认SSC小成员组未满16bit时显示适配问题。
- ESI F000读取实际Info/SubItem默认值`02`/`10 00`/`02 00`，原BitOffs为0/16/32。内置XML的CA=0阻止CA，不阻止权限允许的单项。7000缺默认值显示`?? ??`。
- 本地通用QA XML声明CA=1时按真实F000定义得到6/4Byte；80Byte标量翻页32/32/16，切换外部未解析类型不借用旧类型或值。QA文件仅在artifacts中，不加入产品或提交。
- SSC工作台没有工程配置输入时显示未知；从SSC跳转ESI能力字段正常；ESI弹窗Escape保留原展开字段。基础概念原独立教学SI2仍正确显示4Byte。
- 新来源工作台按需加载；主入口构建496.76kB（未触发500kB告警）。本轮不修改toolbox或其他仓库。
