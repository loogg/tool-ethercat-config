# SDO成员选择与载荷联动修复

2026-10-27，基线v1.6.0。用户截图：单项访问起始SI仍为0，右侧已选:01，状态和载荷仍为1Byte；单Byte还被拉满载荷区域。

原因：成员高亮(selection)和请求起始SI(request.start)分别更新；图按当前字节数均分整栏，无法直观比较1/2/4Byte。

方案：单项模式点协议条目/本地成员同步请求，当前成员由请求派生；手动输入起始SI也联动高亮。CA模式仍只定位成员，避免把点选SI2改成非法CA起点。切到单项模式访问当前查看的成员。状态明确标出本次请求；字节图使用统一的容器相对格宽，每格1Byte，不随当前载荷长度拉伸。
