# ESI 条目工作页显示重构

日期：2026-10-25。用户批准 `docs/ui-prototype/esi-display-review.md` 的方案C，并以方案B作为复杂关系的展开方式。范围是ESI显示与交互，沿用当前解析、规则及计算。

## 实施前验收

- ESI默认按身份、通信、对象字典、PDO、模块/轴、SII导航；原始XML树和未知字段仍可访问。
- 主区显示当前条目，字段名称、原文值、简短含义和来源关联同行。不常驻第三栏，不保留七个并列的全局页签。
- 选择属性/叶字段后，在所属条目的表格中原位展开说明、可写值、当前文件引用、SSC/应用定义关联及局部图。复杂关系不强行塞进窄栏。
- Object、DataType、PDO、Sm、Slots、Dc沿用适合各自数据的表格、成员或位段表达；Index和SI、字典与PDO偏移、固定/测量与容量边界分别保留。
- SSC/应用对应明确是规则关联，当前XML引用显示实际解析状态；没有直接对应不强填三个来源。
- XML原文以按需窗口查看；打开/关闭、复制、跳转和返回保留当前字段上下文。
- 保留已有字段链接、`esiPane`历史链接、多Device/Revision、Module作用域、本地文件只读/异常恢复。
- 键盘可展开和关闭字段；窄屏字段/关联可读，图可切对应表，正文不出现整页横向溢出。

## 实施结构

```text
ESI原有解析和语义模型
        |
显示适配：导航分组 / 所属条目 / 字段行 / 关联入口
        |
ESI导航 ── 选中条目 ── 字段表
                         |
                原位：含义、写法、关联
                         |
                按需：局部图 / XML原文
```

## 验证对象

- RxPDO Entry的Index、SI、DataType、BitLen及其对象引用/容量规则。
- Sm[Outputs] ControlByte的原字节、位段与SSC看门狗对应。
- Slots的对象/PDO步长、模板/实例与单体/多模块；CiA402轴视图。
- 缺失、显式0/false、未知字段、长值与损坏/过大XML。
- 1440×900、1280×720、390×844；实际浏览器检查布局、展开、图/列表、原文和跨入口返回。
- lint、适用测试、生产构建及本地预览；不修改其他仓库、不提交或发布。

本地实现已完成，版本v1.4.0。新增显示适配、条目页和字段局部关系图；提取并复用字典、类型、PDO、模块、轴与原文面板。没有改成新的数据库或工程配对系统。
