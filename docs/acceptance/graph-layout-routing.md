# 关系图连线与响应式排版

日期：2026-10-26。基线：v1.5.2。用户反馈连线重叠、穿过节点和被遮挡，并要求窗口变化时自动排版、查找贴近的项目案例。

## 原因与范围

主图只按全局横向/纵向固定端口，反向边仍从右出、从左入；多个边共用端口与折线通道。其余四个画布各自使用Dagre或蛇形坐标，再由smoothstep独立计算线，未把节点、端口、边、标签一起布局。仅提高连线层级无法解决。

范围：SSC配置主图、应用字段局部关系、ESI字段局部图、XML内部引用、跨文件对应共五类画布。保留字段/关系ID、方向与来源语义、分组容器、文字视图及查阅交互。

## 方案

```text
既有领域图 -> 统一几何输入（节点尺寸、分组、关系、标签）
画布尺寸 -> 去抖/方向评估 -> ELK Worker -> 节点、专用端口、折点、标签矩形
                                         -> React Flow 自定义连线与原有节点
用户缩放/平移 -> 暂停自动适配；适应视图 -> 恢复跟随窗口
```

- ELK在本地Worker执行，页面不向服务发送配置；布局缓存有界，异步结果只应用于当前图和尺寸。
- 配置对象的子项保持父容器内的固定结构；通过父边界端口连接外部关系，内部短线不跨其他子项。
- 节点、端口与标签参与布局；逐边使用引擎折点，避免渲染器重新选路径。正反向和并行边有独立端口。
- 窗口、导航和检查器改变实际画布后重新评估横/纵布局并适配。手动查看时保留视口，点击适应视图恢复。缩放下限允许完整容纳图，不以最小字号限制裁掉节点。
- 任意拓扑不承诺完全零交叉；验收重点为不穿节点、标签不互盖、平行/反向关系可区分，交叉不被误画成连接。

## 实现与验证进展

- 五处均已改用共享ELK模型、端口及实际折点渲染，移除Dagre。领域关系、分组、ID、方向、证据未改动。
- 首次等待真实画布尺寸，后续ResizeObserver去抖140ms；按画布宽高比较横纵布局。有界缓存96份方向布局，同图缩放仅复用几何，失效异步结果不落地。
- 普通点选保留自动适配；使用实际onMove事件识别平移。自定义适应按钮避免React Flow默认fit与自动fit竞争。视口按含边和标签的整个布局范围计算。
- 已知尺寸及端口同时传给React Flow，待画布就绪再刷新DOM端口；复验快速缓存导航和Identity四个子项，未再出现缺线。
- 每个辅助图显式使用独立ReactFlowProvider，从主图打开跨文件弹窗不会改写主图状态。跨文件长标题、路径在卡片范围内截取，完整路径保留title及详情。
- 窄屏内联ESI、XML和跨文件图增加可用高度；自动适配为全图概览，可使用缩放/平移或文字视图读取密集图。

几何回归：642种不同的现有模型 × 横/纵两方向（1284次布局），包括配置及扩展、各应用字段、全部内置ESI字段、XML内部引用、11种跨文件主题。检查节点不相交、端点及专用端口精确、折线正交、不穿非祖先卡片、不共线重叠、不穿其他标签、标签不互盖；另有反向/并行/菱形/跨层合成图、自动方向、无效输入拒绝。166项完整测试已通过，发布前复跑。
