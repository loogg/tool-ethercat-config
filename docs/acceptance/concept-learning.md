# 基础概念与场景理解验收

日期：2026-10-25。阶段：v1.5.0已提交、推送并完成Pages部署；本地、线上资源与首页显示验证完成。

## 范围与依据

用户批准上一轮推荐的“概念→场景理解→配置对应”方案，要求合理布局、易于理解。沿用纯前端、白色工作台和蓝色重点，不引入设备连接、后端或在线知识依赖。用户笔记用于确定主题，公开内容采用通用示例和官方资料。

覆盖六个主题：通信角色；对象与地址；SM/PDO与数据通路；同步与事件；状态与指示灯；描述文件与启动。已有18条协议参考纳入主题，旧URL、收藏和查阅上下文继续有效。配置字段可原位解释术语并进入完整场景。

用户补充（实施中）：基础概念位于查阅导航最上面，首次进入工具需有独立首页。首页采用任务入口模型，四个主入口依次为基础概念、SSC Tool、应用对象字典、ESI；下面使用现有主题、计算器和真实最近记录派生内容，避免重复知识或伪统计。

### 本地模型与交互

- 六个主题、29个术语、11种教学场景、33个讲解步骤；18个旧条目保留ID，以及折叠技术要点、示例、关联和公开来源。
- 配置入口在实际教学XML/应用表中解析核对。输入/输出同步选择SM2/3、Rx/TxPDO与容量字段；Mailbox不冒用PDO容量规则。
- 实际操作PDO容量：48 bit→6 B；32 bit内部宽度得到8 B单份跨度与24 B三缓冲占用；1 bit映射得到1 B线上长度、4 B内部跨度且不使用额外缓冲；没有活动成员得到0占用。空容量输入可错误恢复。
- 学习步骤/场景在当前历史项内更新URL，浏览器返回直接回到来源字段。ESI输入SM3的ControlByte仍展开，APP DataType返回仍选中原BOOL成员；刷新保留教学参数。
- 看门狗原位解释直达独立双链路图解。150 ms时停止刷新侧仍剩10 ms；所选SM中断场景与150 ms游标可原样带入完整时序。
- LATCH650µs和应用读取1550µs分别显示；同步参数可错误恢复，完整时序收到同样参数。灯效播放/暂停、0与1599ms时刻、BOOT回INIT验证；减少动画下播放禁用，恢复媒体设置后不自动播放。
- 首页面向四个主入口；空地址、品牌、配置卡片和五类计算器实际跳转正常。基础概念排在SSC/应用/ESI之前；最近列表仅使用真实记录。
- 首页搜索保留首页背景，Esc关闭并保留查询，避免原生搜索输入默认清空后重开结果。准确术语检索可落在相应场景步骤。
- 390px各主题page/content宽度无横向溢出；角色与引用链在小屏转为紧凑纵向。实际点击PDI节点、邮箱请求应答、跨字节FMMU位映射、文件仿真和Profile差异均正常。
