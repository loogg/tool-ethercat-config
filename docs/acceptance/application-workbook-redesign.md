# 应用对象字典工作台

日期：2026-10-24。用户批准上一轮 C 模型，并要求移除 SSC 总览的两个置顶示例。本轮为实施任务。

## 实施前范围与标准

- SSC 总览移除 MIN_PD_CYCLE_TIME / MAX_PD_OUTPUT_SIZE 推荐卡片，按原分组查阅；首次进入及品牌首页回到 SSC 总览。
- APP 使用工作簿、工作表、对象头、成员、字段定义、字段取值与原始来源的关联模型。按用户后续纠正，排除具体项目，只包含通用示例；不改原文件，不增加后台和文件上传流程。
- 表格为主要阅读界面，按工作表切换，支持对象折叠、筛选、常用列/全部列、生成项预览。说明按当前字段与所属层级变化，不把整列作为一个脱离上下文的配置。
- Base_Device、Digital_Input、Digital_Output 的 Module Ident 与 F030 引用正确；基础表和模块表 C3 含义不同，读取以字段名为准。
- 区分 VARIABLE 单值、RECORD/ARRAY 对象头与成员；对象头 Access 不覆盖成员；空白不变成 0；没有来源的 SI0 标为生成规则预览。
- 槽位页显示允许模块、默认模块、索引增量的来源与按条件展开的示例。模板、规则预览、未核对生成产物分别表达；没有 PDO Mapping/Assignment 定义时不编造活动映射或具体自动生成的 PDO 索引。
- 选中单元格可查看简短解释、原表位置及局部关系图；关系节点保留文件/表/对象上下文，边有关系类型和条件，支持跳转相关 SSC/ESI 配置。
- 保留旧 APP 字段链接、全局搜索、收藏、历史导航；工作表与单元格定位可复制深链接及刷新恢复。
- 真实浏览器检查 SSC 总览、三张模块表、槽位、字段说明、关系图、筛选空态、全列滚动、手机和平板布局与键盘操作。具体项目条目与数据的排除单独核对。执行 lint/test/build；只在本仓库运行。

## 方案

工作簿快照 → 领域解析（对象/成员/槽位/模块）→ 字段语义与规则预览 → 表格、上下文说明、局部关系图。

APP 旧字段资料作为 FieldDefinition；真实单元格作为 ValueOccurrence。模块模板与实例展开结果分离；原始数据只有来源位置，不执行工作簿内说明。

### 后续纠正（已实现并验证）

- 用户要求覆盖普通/单体应用，不能只展示多模块。统一对象/成员为核心，模块模板与 Slot 为可选层；模块数量不决定应用类型。新增通用单体 I/O 教学定义，明确不是项目文件或真实工作簿快照。
- 每列增加可填写内容、全部枚举或格式、范围、空白含义、适用层级、例子和来源；列标题直接进入填写手册。依据 ET9300 V1.10 §6.4.1、13.4、13.5，避免只展示一个样例值。
- 补充为三种通用场景：普通单体 I/O、模块化单实例 I/O、模块化双实例 I/O；前两项为明确标记的教学定义，后一项为原通用模板快照。
- 三种场景实际切换：普通应用无 Slot 按钮，单实例显示1个 Slot 且同一模板包含输入/输出，双实例显示2个 Slot；领域测试确认数量不决定结构类型。
- B–P共15列填写手册逐项实际切换，枚举、格式、空白、示例、来源均可读取。Access 13项、DataType 34项，检索UINT16显示16位及0…65535；无结果提示、Esc关闭与键盘重新打开通过。
- 范例 ro,wr_preop 的复制实际验证，并恢复测试前剪贴板。普通对象图显示直接使用定义索引，不插入 Slot 偏移。
- 390×844填写手册实际观察，面板在8…382px范围，内部无横向溢出。生产日志无 error/warn。
- 最终候选 lint、68/68测试、构建通过。此前64项记录是前一候选的过程记录，以本段最终结果为准。
