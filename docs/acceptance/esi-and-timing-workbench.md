# ESI工作台与交互时序改版

日期：2026-10-24。用户批准ESI推荐模型，要求重做时序图，并为适合时序表达的配置补充图示。本轮连续实施，不改其他仓库、不发布外部站点。

## 实施前方案与验收标准

### ESI

- XML原文/源位置、设备语义、字段规则、Profile解释分层。仅内置通用教学XML，可在浏览器本地打开文件；不打包用户项目，不上传或持久化文件正文。
- 一个文件多Device/Revision分别选择；Device、Module定义的字典、PDO和类型查找保留作用域，不全局混汇。
- 左导航显示XML层级，主区提供结构属性、对象、PDO、Profile与原文；右侧短说明、可填写值、单位、引用和依据跟随节点/属性。
- ProfileNo与模块组织分开。5001按MDP功能结构理解，402提供轴/状态/模式解释；6040作为Rx控制字，不用6xxx全局推定输入。轴步长只在有依据的示例/解读规则下使用。
- 类型引用、PDO到对象成员、Slot到Module及条件索引展开可追踪。源值、推导预览、缺失/未知/外部依赖分开；缺失不补0，false和0不丢失。
- 原始XPath与可获取的行位置可复制；原文不因模型不识别而丢弃。未知字段仍可查看。XML解析成功不等于完整XSD或固件合规；当前参考规则有明确出处和覆盖边界。
- 保留旧ESI字段URL/搜索入口，增加当前XML、Device、节点、视图深链接；本地文件刷新失效时明确提示重新打开。

### 时序

- 风格采用共用时间轴的工程轨道，参考PulseView/Saleae的游标测量、Perfetto的事件选择/范围导航、WaveDrom的数字时序符号；不再使用两张大卡片各画一根线。
- 支持点击/拖动观察点、选择事件解释、播放/暂停、前后事件、缩放/适应、A/B游标差值以及可编辑演示参数。键盘操作、空/错误状态和窄屏可用；不使用虚构的实测/硬件连接状态。
- 审查现有配置，给真实涉及先后/等待/周期/缓冲交换的类型添加入口：看门狗、同步/周期预算、AL状态超时、SDO回调/挂起、缓冲角色交换，以及402驱动状态的逻辑步骤。纯地址/身份/静态类型不编造时序。
- 看门狗使用共享Divider、独立计数和触发；参数变化同步事件/到期状态，Count=0只禁用本侧；持续触发间隔过长同样会出现到期窗口。保留0值并带入独立计算器。
- 周期预算、状态等待、异步回调的示例有明示假设、输入绑定、单位和来源；不把图示过程自动等同所有固件的实际调用顺序。缓冲和402状态使用逻辑步骤，不杜撰物理毫秒。
- 时序入口由显式映射及模型判断提供，记录覆盖项/不适用原因，相关APP/ESI节点同样可进入。
