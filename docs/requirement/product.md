# EtherCAT 配置查阅工作台

2026-10-24，用户授权一次完成全部功能、逐项实现与测试，最后交付。基于用户 Notion Ethercat 笔记、Cap 风格参考及 Refactoring UI 九章。独立仓库 tool-ethercat-config；不改兄弟仓库，不发布到外部服务。

## 使用结果

从 SSC 宏、Excel 字段、ESI XML 路径、对象索引或中文意图找到配置项；理解含义、填法、范围与单位、适用条件、常见误用；沿显式语义关系与反向引用继续查；在条目内打开计算器，看到输入、公式、代入和输出。

## 本次完整交付范围

- 分类与来源双维度浏览；全文关键词/别名/索引搜索；搜索无结果恢复。
- SSC 配置，XLSX 对象字典字段，ESI 结构与属性，以及 CoE、SM、PDO、DC、邮箱、状态、硬件相关基础条目。
- 详情页包括字段定位、规则、示例、参考来源、适用范围、双向关联；深链接、浏览器返回、复制标识与链接。
- 收藏/最近阅读本地保存；收藏空态、来源与使用说明。
- PDO 32 位映射编解码、PDO 字段布局与长度、SM 内存规划与重叠/边界/对齐检查、SM/PDI 看门狗时间计算、SM ControlByte 位解释。
- 桌面工作台布局与小屏单列交互、键盘操作、焦点反馈、减少动画支持。
- 原创应用标识、favicon、本地字体、无运行时外部依赖；构建产物和启动说明。

## 边界

专业查阅和计算工具；没有设备通信、没有修改实际设备、没有 Notion 在线依赖。用户没有要求文件导入/导出配置生成器，当前不提供整份 XLSX/ESI 导入和生成。计算中的示例、静态 ESI 描述与实际运行配置明确区分。芯片 RAM 范围由用户输入，不能把某个芯片的数值当通用规范。SSC 配置行为按参考版本说明，非全文规范替代。

## 用户修正：按实体组织查阅入口

2026-10-24，本轮按用户明确的实体优先查阅方式调整导航。以上初始范围记录保留；入口组织以本节为准。

- 一级入口为 SSC Tool、应用定义文件、ESI 设备描述文件和基础概念。Excel 文件在界面中称“应用定义文件”（短名“应用定义”），不以 XLSX 作为实体名称。
- 默认打开 SSC Tool 概览与配置树。树按实际界面顺序保留 SlaveInformation、Generic、Hardware、EtherCAT State Machine、Synchronisation、Application（下含 ProcessData）、Mailbox、Compiler。
- 应用定义文件分为“对象字典字段”和“设备与模块”；ESI 按设备身份与目录、通信与同步、对象字典描述、插槽与模块、EEPROM / SII 分组。
- 条目的主归属依据真实来源实体。SSC 配置按 SSC Tool 路径定位，应用定义按主要 XLSX 来源识别。具有 SSC、Excel 或 ESI 交叉引用的机制解释仍属于基础概念，不能因为引用存在而误列为配置字段。
- 详情页保留跨实体关联。跳转到相关字段时，目标实体和所在分组应同步高亮；跨实体浏览可追踪、可返回。
- 全局搜索始终检索全部实体。深链接与浏览器返回保留 collection / group 导航上下文；原有收藏、最近阅读、计算工具和使用说明继续可用。
- Compiler 保留可查阅的概览入口。未核实的字段不补造成通用宏；明确所用 SSC 版本、厂商 Config.xml 和编译器适用条件。

导航契约集中在 `src/data/navigation.js`：`collections` 提供实体和分组顺序；`navigationEntries` 提供实体概览与 Compiler 概览；`getEntryNavigation(entry, origin)` 依据原始数据集及真实主来源生成条目归属，不改写原有技术条目。
